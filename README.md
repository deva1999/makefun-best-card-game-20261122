**Stormspire Duel** is an original turn-based card battler played against Vex, the Clockwork Duchess, atop a living storm. Forty named cards across four suits — Ember, Tide, Gale and Stone — fight in a suit cycle where each suit beats one other for +3 power, plus eight relic cards with their own effects: the Cinder Crown burns, the Tidecaller Pearl mends, the Gale Mirror copies, the Stoneheart Aegis wards. Every card costs embers, you gain two per trick, and every five tricks the storm rises and every trick hits harder. First to bring the other to 0 life takes the spire. The game runs entirely offline from static files — no network, no build step.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 — click a card (or press 1–5) and Enter to play it, C to channel embers, R to restart.
